LIMITLESS INNOVATIONS WEBSITE - MESSAGES, ORDERS AND THE ORDER DESK

WHAT IT DOES
- The "Message us" form on the website sends the visitor's name, email, phone
  and message to your own database (Cloudflare D1, in your Cloudflare account).
  Nothing goes through the visitor's email program.
- The trade basket sends orders the same way.
- You read and manage both at   https://limitlessinnovations.co.uk/desk
  (password protected). Each message has "Reply by email" and "Call" buttons;
  each order has a status (new, confirmed, ordered from supplier, dispatched,
  closed) and, per item, links to suppliers.
- Clearing out: every message and order has a Delete button. Or set a
  message to Archived (an order to Closed or Cancelled) and use
  "Clear archived messages" / "Clear closed and cancelled orders" to remove
  them all at once. Tick "Show archived and closed too" to see them first.
- Suppliers tab: every product in the shop with where to buy it and the
  price seen on the date shown. This is for you when an order comes in;
  customers never see it. Filter by range or search by name, brand or group.
  The links live in worker/suppliers.js; the product list is generated from
  the website's shop data, so new products appear automatically.
- Optionally, every new message and order also emails you.

------------------------------------------------------------------------
STEP 1 - SET THE DESK PASSWORD (2 minutes, required)
------------------------------------------------------------------------
1. Cloudflare dashboard > Workers & Pages > limitless-innovations-website
   > Settings > Variables and Secrets > Add.
2. Type: Secret.  Name: DESK_PASSWORD.  Value: a long password of your choice
   (12+ characters). Save.
3. Open https://limitlessinnovations.co.uk/desk and log in with it.
   Changing the password later logs every device out.

------------------------------------------------------------------------
STEP 1b - HIDE THE DESK AT A PRIVATE ADDRESS (1 minute, recommended)
------------------------------------------------------------------------
By default the login page is at /desk, which anyone could guess (it is
still password protected). To make the login page itself private:
1. Same place as step 1: Add > Type: Secret. Name: DESK_PATH.
   Value: a private address of your own, letters, numbers and dashes only,
   e.g.  desk-7k3q9x-limitless
2. Save. From then on the desk is at
   https://limitlessinnovations.co.uk/desk-7k3q9x-limitless
   and /desk is just a missing page like any other. Bookmark the new one.
   Change the value any time to move it; remove it to go back to /desk.

------------------------------------------------------------------------
STEP 2 - EMAIL ALERTS (5 minutes, optional but recommended)
------------------------------------------------------------------------
Without this step the desk still records everything; you just have to open
it to see new items. With it, each message and order also arrives at
info@limitlessinnovations.co.uk.

1. Create a free account at https://resend.com using info@limitlessinnovations.co.uk
   (the free plan sends 100 emails a day, 3,000 a month; alerts use one each).
2. In Resend: API Keys > Create > name it "Website alerts" > copy the key.
3. Cloudflare > the Worker > Settings > Variables and Secrets > Add:
   Type: Secret.  Name: RESEND_API_KEY.  Value: the key. Save.
4. Send yourself a test message from the website form. The alert arrives from
   "Limitless website <onboarding@resend.dev>". On the free plan that sender
   can only email the address the Resend account was created with, which is
   why step 1 uses info@limitlessinnovations.co.uk.

   To send from your own domain instead (so alerts come from
   website@limitlessinnovations.co.uk and can go to any address):
   Resend > Domains > Add limitlessinnovations.co.uk > it shows DNS records >
   add them in Cloudflare > DNS (they are TXT/MX records for a subdomain and
   do not affect your normal email). Then in the Worker's variables add
   Text  ALERT_FROM = Limitless website <website@limitlessinnovations.co.uk>

To change where alerts go: Worker > Settings > Variables > ALERT_TO.

------------------------------------------------------------------------
PROTECTION ALREADY BUILT IN
------------------------------------------------------------------------
- The form and the basket only accept submissions that come from
  limitlessinnovations.co.uk itself (the browser tells the server where a
  submission came from; anything else is refused). So nobody can point a
  script at the server and flood it from elsewhere.
- A hidden field and a minimum time on the form catch bots.
- Each visitor (by internet address) can send at most 5 messages and 5
  orders an hour, and gets 5 login attempts an hour at the desk. After
  that they are refused until the hour is up.
- With DESK_PATH set (step 1b) the login page is at an address only you
  know; /desk shows nothing.
- The desk is never indexed by search engines, all its pages are private,
  and the login cookie is HTTP-only, secure, tied to your password and
  expires after 30 days. Changing the password logs every device out.
- Card details are never taken or stored anywhere on the site.

------------------------------------------------------------------------
IF SOMETHING LOOKS WRONG
------------------------------------------------------------------------
- Form says "couldn't send": the Worker may not have finished deploying
  (wait a minute) or the D1 binding is missing (wrangler.jsonc). The form
  then offers the visitor a normal email link instead, so nothing is lost.
- Desk says "not switched on": DESK_PASSWORD is missing (step 1).
- No alert emails: check RESEND_API_KEY and, in Resend, the Logs page.
